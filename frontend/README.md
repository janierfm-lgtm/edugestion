# EduGestión — Frontend

SPA en React 19 + Vite + Tailwind CSS v4 que consume la API de `../backend`.

Ver la documentación completa del proyecto en el [README de la raíz del repositorio](../README.md).

## Scripts

```bash
npm install
npm run dev       # servidor de desarrollo (http://localhost:5173)
npm run build     # build de producción en dist/
npm run preview   # sirve el build de producción localmente
npm run lint       # oxlint
```
